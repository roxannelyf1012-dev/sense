# SENSE — A rattlesnake sensory experience

An immersive, two-scene web experience inspired by how rattlesnakes sense their environment. It is built with plain HTML, CSS, and Canvas, with no install step or framework dependency.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static file server. For example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Interactions

- Move or tap around the first scene to explore warm sources and ground vibrations.
- Use the four sensory controls to toggle visual layers and read concise explanations.
- Select **Flick to sample** to trigger the forked chemical trail.
- Hover, focus, or tap the anatomy points on the second scene.
- The motion control and the operating system reduced-motion preference both reduce animation.

The sensory visuals are artistic interpretations. Rattlesnakes detect infrared radiation with pit organs; the artwork does not imply that snakes see a human-style thermal camera image.
